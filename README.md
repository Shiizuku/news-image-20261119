An entry for make.fun's **news-image-20261119** bounty ("Sum up 19 November's
world news in one image"), built by @qyxra.

One broadsheet front page for Thursday 19 November 2026:

- **GTA VI day** — the world queues at midnight for the launch.
- **Shenzhen summit** — Trump, Xi and Putin at one table.
- **Voyager 1** — one light-day from home, 25.9 billion km out.
- **Record IPO** — the biggest market debut in history.

`main.py` copies `entry.png` to the output directory (`/output`, or
`$MAKEFUN_OUTPUT_DIR` outside the grader), byte for byte, so repeated runs
are identical. The image is a 1024x823 PNG of about 400 KB.
